# 详细全面笔记的默认标准

生成课程复习笔记前读取本文件。用户未明确要求精简、速记或限定范围时，默认提供详细全面的讲解，帮助深入掌握课件内容并用中英文复述、分析与作答。用户本次指定的范围和深度优先。

## 1. 逐页覆盖原资料

- 对照每页正文和实际页面图像检查内容；单独提取文字不能证明图表已读完整。对 PPT/PPTX 读取原文件的非空演讲者备注；其他格式读取实际存在的批注、脚注或讲解备注。
- 保留教学相关的定义、分类及子类、性质、机制、条件、限制与例外、数值及单位、公式、比较维度、图表、原例、复习题、学习目标和讨论题。多个页面讲同一知识点可合并成卡片，但每页提供的新信息都须保留。
- 图像解释包含与知识相关的标注、箭头方向、参与者及关系；图表包含轴、单位、图例、条件和趋势；比较表保留全部教学行列及差异。原图可就近嵌入辅助理解，但正文仍须解释读图方法和结论。定性图没有精确值时不编造数值。
- 封面、目录、过渡标题、致谢以及纯装饰内容可在内部记录为非教学页。同样的教学内容可说明重复对应；不能把难读、篇幅较长或重要度较低的内容当作无关信息跳过。
- 看不清、提取失败或缺失的部分先尝试读取原文件或更清晰的页面。仍无法确认时明确记录缺口并告知用户，保留已完成内容，不虚构信息或宣称完整覆盖。

## 2. 保留并详解全部教学原例

每个原课件教学例子都在相关知识卡中有可辨认的「课件原例 / Original slide example」内容块。一个块可包含多个分开标明的例子；保留名称和真实页码，不以自行编造的例子替换原例。

按例子实际提供的信息展开：

1. **背景与条件**：涉及的对象、材料、情境、实验条件或比较方案；保留课件给出的具体数值。
2. **过程与步骤**：谁识别谁、先后发生什么、关键机制和中间环节；过程型例子用编号步骤，比较型例子用表格。
3. **结果与读图**：观察到了什么、图示或表格如何支持结论；区分观察结果与推导解释。
4. **说明的原理**：把例子与定义、分类或机制连接起来，给出可用于英文简答的组织要点。
5. **易错点与边界**：哪里容易混淆，哪些条件改变会影响结论，哪些结论不能由此推出。

某例只提供名称或简单图示时，解释它所能支持的原理并注明可用信息，不能补写不存在的实验数据、步骤或教师答案。课件已有习题答案须保留并讲解；未给答案的讨论题可以提供明确标为「参考推导 / Reasoned model answer」的分析。

## 3. 展开讲解深度

- 每个知识点讲清是什么、为什么、如何应用及易错处。机制给出必要因果链和中间步骤；过程给出顺序及每步目的；分类给出划分依据、全部相关子类、区别和对应原例；数值和结论保留适用条件。
- 新术语和缩写首次出现就近解释，中英采用一致的事实、条件和推理。章末词汇表汇总术语，正文仍需完成理解所需的解释。
- 易混概念作逐维度对照。包含原理或过程时，正文要足以让读者不回看课件也能说明其关系、步骤和案例结论。
- 一句话 TL;DR 和每节小结用于提炼核心，正文按内容需要充分展开。不得为保持卡片短小、达到固定字数或固定卡片数量而删减教学信息；也不通过套话、重复或无关拓展增加篇幅。
- 补足理解所必需的背景时标为「理解补充 / Explanatory supplement」。遇到原资料内部矛盾或疑似错误，在对应处标为「校对提醒 / Accuracy note」，说明原文、冲突和核对依据；无法确定时保留疑问。外部纠错依据给出可核查的来源，补充内容不冒充课件原文或教师考纲。

## 4. 保持清晰排版

沿用 `note-layout.md` 的主题大节、独立知识卡、环节小标题和就近中英配对。较长机制拆为编号步骤，多个原例分别标明，对比使用表格，易错提醒单独呈现；节末小结、自测和章末词汇表独立放置。内容增加时扩展卡片内分块，不能把讲解、原例和易错点糅成一段。

## 5. 交付前覆盖核对

在 `.epa_work/coverage/<章id>.json` 保存内部覆盖记录，至少包含：原文件与真实页码/章节定位、该处教学内容清单（正文/图表/备注/原例）、对应知识组件与笔记卡、非教学或重复说明、尚未确认的缺口。记录格式可适配资料类型，但不能只列页码而不核对页内信息。

写完后重新对照原资料与该记录，逐项确认：

- 所有教学页的正文、图表、非空备注都有对应讲解，图表并非仅以图片或链接代替解释。
- 所有教学原例都已保留，并按现有信息解释条件、过程、结果和原理。
- 分类、比较表、数值及单位、公式、条件、限制、例外和原习题没有在归纳中丢失。
- 因果链和操作步骤没有推理跳跃；核心结论之外有充分正文。
- 中英文同样完整；分区、卡片、原例、易错、小结、自测和词汇表清晰可辨。

发现遗漏先补齐再交付；剩余无法确认的缺口须在交付说明中列明。覆盖记录供内部核对，面向学生的笔记保留清晰学习结构。
