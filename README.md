# Bilingual-exampass：中英对照笔记与考试复习助手

**把课件整理成能读懂、能复习、能自测的中英对照学习资料。**

Bilingual-exampass 是面向 Codex 的课程复习技能。提供 PPTX、Word（DOCX）或 PDF 课件后，它会按章节梳理知识结构，结合原文、图表和备注编写详细笔记，再按需要生成平板批注用 PDF、带原课件对照和英文测验的 HTML，以及知识图谱、期末模拟试卷和批改报告。

[English](README.md) · [技能执行规则](SKILL.md) · [GitHub 仓库](https://github.com/DX-David/Bilingual-exampass)

## 适合谁使用

- **双语或全英文课程的学生**：用中文理解概念，同时掌握对应英文表达和专业术语。
- **需要系统复习的学生**：把分散的课件内容组织成章节、知识卡、小结和自测，方便检查薄弱环节。
- **习惯在平板上学习的人**：生成独立笔记 PDF，导入笔记软件后圈画、标注和补充。
- **需要练习与命题参考的人**：生成章节测验或期末试卷，结合答案解析进行复习。

## 三种输出，自行选择

提供课件后，如果尚未指定结果，技能会先让你选择以下三种模式：

| 模式 | 包含内容 | 格式与用途 |
| --- | --- | --- |
| **纯笔记** | 完整双语笔记、必要的正文图表、笔记内自测与展开答案、章末词汇表 | PDF，便于导入平板批注，不带 PPT 旁栏和独立章节测验 |
| **完整笔记** | 完整双语笔记、原课件全部页对照、英文互动章节测验 | HTML，在浏览器中阅读、对照和答题 |
| **两者都要** | 同一份笔记正文分别导出以上两种结果 | PDF + HTML，兼顾手写批注和互动复习 |

已经明确选择时会直接执行；同一批课件沿用所选模式。两种文件共用同一份笔记正文，保持知识点、术语和讲解深度一致。

## 核心功能

### 1. 详细、全面的中英对照笔记

按课件逐页核对正文、图表及非空演讲者备注，保留教学原例、分类、数值、单位、条件、限制和例外，并展开机制、因果关系和操作步骤。遇到看不清或不能确认的内容，会记录缺口；理解补充、参考推导和校对提醒分别标明。

笔记采用“章首概览 → 主题大节 → 独立知识卡 → 大节小结与自测 → 章末词汇表”的结构。知识卡围绕具体问题展开，依次说明核心结论、为什么重要、是什么、如何应用，以及容易混淆的地方。

讲解、原例、小结、自测问题及答案均按**中文段落后紧跟对应英文段落**的方式编排。两种语言表达相同的事实、条件和推理，不只翻译标题或摘要，也不额外添加独立的语言标签行。

### 2. 清晰紧凑的阅读排版

- 用章节标题、知识卡和环节小标题组织长篇内容，避免把多种用途混在一段里。
- 减少段落、板块和卡片之间重复叠加的留白，保持适合连续阅读的密度。
- 用重点标注、易错提醒和“必考／重点／高频／了解”标签辅助复习。标签用于安排复习顺序，不代表教师公布的考试范围。
- 对易混概念使用比较表，对较长过程按步骤解释。
- 每章最后汇总重要英文术语、中文对应词、英文定义和中文释义。

### 3. 适合平板批注的纯笔记 PDF

纯笔记模式直接从笔记正文导出，默认采用 A4 竖版，保留可选中、可搜索的文字，嵌入中英文字体，并加入页码与目录书签。自测参考答案展开显示，便于离线阅读和手写标注。

导出时检查文字完整性、缺字、分页、表格跨页和标题位置。生成的 PDF 可用于平板笔记软件；具体导入方式及批注体验取决于所用软件。

### 4. 原课件对照与定位

完整 HTML 将双语笔记和原课件放在同一页面，右侧展示原课件页面及原文。点击知识点标题旁的页码标记，可定位到相应课件页，便于检查图示、术语和上下文。

默认保留全部原页；需要时也可以指定只展示重点页。PPTX 通过转换副本生成页面对照，保留原始课件。

### 5. 全英文互动章节测验

完整笔记包含独立的章节测验。题干、选项、答案、解析、易错提示和测验界面使用英文，方便练习课程术语和英文作答。

支持单选、多选、判断、填空、简答、计算、代码、问答和综合题。题型根据课程内容选择，不要求每门课都包含所有题型。命题围绕知识点展开，兼顾记忆、理解、应用和分析，并检查选择题答案分布及干扰项的合理性。

网页可自动判定客观题，并展示参考答案和解析。简答、计算、代码等主观题需要结合参考答案评阅，或继续交给 AI 批改；网页即时得分不等于主观题已经评定完毕。

### 6. 作答导出与 AI 批改

完成 HTML 测验后，可通过页面中的批改入口导出作答 JSON，再交给技能处理。主观题答题区支持粘贴图片，导出时可随文字答案一起保留，便于提交手写过程或其他图像作答。

AI 批改会核对客观题、评阅主观题、给出得分与英文评语，并生成 HTML 报告，汇总总分、客观题与主观题得分、错题及知识点掌握情况。

这里的批改入口用于**导出作答并衔接 AI 批改流程**，不是在普通浏览器页面中直接调用在线模型。

### 7. 交互式知识图谱

知识图谱按章节和知识组件展示课程结构，支持依赖关系连线、枢纽概念标记、搜索、缩放和面板宽度调整。点击知识点可打开笔记卡，输入文字或粘贴图片，也可重命名节点。

图谱笔记保存在当前浏览器的本地存储中，不自动跨设备同步。已有知识骨架时可保留依赖与重要度等信息；缺少骨架时也能生成简化树，但信息深度较低。

### 8. 期末模拟试卷与真题风格参考

可针对整门课程或指定章节出题，并按范围、难度、时长和题型偏好设计蓝图。题型与分值依据课程内容决定，整卷默认按 100 分组织，单章可按时长调整。

提供参考真题后，可分析其题型、分值、问法和难度，在课件范围内编写新的题目。生成结果包括交互式试卷和答案解析 HTML，可使用浏览器打印功能另存为 PDF。

## 如何使用

在支持本地技能的 Codex 环境中安装后，调用 `$bilingual-exampass`，提供课件文件或课程目录即可。也可以直接用自然语言说明目标。

### 整理课件

```text
用 $bilingual-exampass 整理这份课件，生成详细的中英对照笔记。
```

### 指定输出

```text
这次只要纯笔记 PDF，方便导入平板批注。
```

```text
两者都要：纯笔记 PDF，以及带 PPT 对照和英文测验的完整 HTML。
```

### 批改作答

```text
$bilingual-exampass grade <作答JSON路径>
```

### 生成知识图谱

```text
$bilingual-exampass graph <课程目录>
```

### 生成模拟试卷

```text
$bilingual-exampass final <课程目录>
$bilingual-exampass final <课程目录> --chapter <章节名称>
$bilingual-exampass final <课程目录> --ref <参考真题路径>
```

这些是交给 Codex 的技能调用示例，不是直接在系统终端中执行的命令。`--ref` 和 `--chapter` 可以组合使用；也可用自然语言补充时长、难度或不考的题型。

## 安装与运行环境

本项目由技能指令、Python 脚本和网页模板共同组成。资料提取与文件渲染由脚本辅助完成，知识组织、双语讲解、命题和内容复核需要 AI 执行技能流程。

首次在 Windows 上安装时，可将仓库克隆到尚不存在的技能目录：

```powershell
git clone https://github.com/DX-David/Bilingual-exampass.git "$env:USERPROFILE\.codex\skills\bilingual-exampass"
```

在仓库目录中安装 Python 依赖：

```powershell
python -m pip install -r requirements.txt
```

如果已经安装并能调用本技能，无需重新克隆。PPTX 整页转换需要 Windows PowerShell 和本机可用的 Microsoft PowerPoint。纯笔记 PDF 按可用的 PDF 技能或本地 PDF 工具导出；中文字体和分页需在生成时核对。

扫描件、图片型表格及复杂图示需要可用的视觉识别或 OCR 能力。HTML 中的公式排版依赖 MathJax，加载其外部资源时需要网络；普通页面内容和已嵌入的课件图像保存在文件内。

## 文件会保存在哪里

未另行指定时，每章结果保存在课程目录的 `EPA/` 文件夹：

| 结果 | 默认文件名 |
| --- | --- |
| 纯笔记 PDF | `<章名>_纯笔记.pdf` |
| 完整笔记 HTML | `<章名>.html` |

提取内容、知识骨架、笔记源稿、题库及覆盖记录保存在 `.epa_work/`，用于继续处理与核对。AI 批改报告默认保存到作答 JSON 所在目录。

仓库的忽略规则会排除常见课件格式、生成笔记目录及环境配置文件，便于将技能代码和个人学习资料分开管理。
