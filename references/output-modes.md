# 输出选择与交付

本文件用于默认课件笔记流程。用户提供课件后，先确认「纯笔记」「完整笔记（含PPT对照）」「两者都要」。明确选择直接执行，未选择时询问并等待，不擅自预选。用户当次指定的格式、范围和路径优先。

## 选择与复用

- 用可用的选择工具展示三个选项；没有选择工具时用普通消息列出三选项，不要求用户上传新文件或修改配置。
- 同一批资料只问一次，后续处理该批章节沿用选择。用户说改成另一模式时更新选择；新增独立一批课件且未指定时再询问。
- 将已确认的选择存入 `<课程目录>/.epa_work/output_selection.json`，便于续跑。例如选择纯笔记时保存 `{"mode":"notes_pdf"}`；完整笔记使用 `full_html`，两者都要使用 `both`。`mode` 只保存一个已确认的实际值。
- 若当前指令与旧记录冲突，采用当前指令。当前批次尚未选择时，不用历史偏好或等待时长代替回答。
- 等待选择期间可提取资料并核对图表/备注。选择只影响最终包装和独立题库，不降低笔记深度或逐页覆盖。
- 后续仅要求转换已生成笔记时，复用现有正文导出，不重新出题或改写学习内容。

## 三种模式

| mode | 展示名称 | 每章交付 |
| --- | --- | --- |
| `notes_pdf` | 纯笔记 | `EPA/<章名>_纯笔记.pdf` |
| `full_html` | 完整笔记（含PPT对照） | `EPA/<章名>.html` |
| `both` | 两者都要 | 上述PDF及HTML各一份 |

以上为未指定路径时的命名。输出目录里可能已有旧结果，应清楚标出本次生成的文件；不因切换模式删除用户已有文件。

### 纯笔记PDF

- 从 `.epa_work/notes/<章id>.html` 正文源稿生成；不要把包含PPT旁栏和测验的完整页面直接整页打印进PDF。
- 保留完整中英对照知识卡、教学原例、必要图表、易错提醒、章节小结、笔记内自测及展开的参考答案、章末词汇表。去掉PPT对照栏、浏览器按钮、互动控件和独立章节测验。必要的正文教学插图仍应保留，不能把「无PPT旁栏」解释为删除笔记内所有图表。
- 未另指定时采用A4竖版、可选中/搜索的文字，嵌入可用中英文字体，加入页码及目录书签。采用 `note-layout.md` 的紧凑密度；保留适量页边距供圈画，不额外插入空白页。
- 应用当前可用的PDF技能处理导出和视觉验收；没有该技能时，可使用本地ReportLab等PDF工具。导出方式须保留文字层、完整内容和分页质量，不能用整页截图冒充可选中文字的PDF。
- 核对正文、表格和展开答案完整；检查中文、英文、希腊字母和上下标无缺字；逐页渲染检查溢出、裁切、表格跨页及标题孤行。解除不必要的加密或批注权限限制。未实际在平板应用测试时，不声称已完成该应用内导入验证。
- 此模式不需要 `.epa_work/questions/<章id>.json`，不因缺少独立题库阻止PDF交付，也不为了满足完整页脚本而另出题。

### 完整笔记HTML

- 保持现有双语笔记 + 原课件对照 + 全英文互动测验流程，使用 `scripts/render_chapters.py <课程目录> full`。
- 保留全部原页、有效页码跳转、目录、折叠自测答案和词汇表。核对PPTX转换后引用仍能跳转，避免无效或重复页码标记。
- 测验题干、选项、答案、解析、提示和测验界面均为英文；核对评分与答案导出。
- HTML是可交互的完整结果，不以纯笔记PDF代替它。若用户另指定「完整PDF」等格式，按明确要求适配，不强制返回HTML。

### 两者都要

- PDF和HTML共享同一份笔记源稿、知识点顺序和术语，不能分别写成内容深度不同的两套笔记。
- PDF按纯笔记规则导出，HTML按完整规则渲染；各自完成验收，并分别提供文件入口。
- 只完成一种时，明确说明哪一份可用、哪一份尚未完成，不把单一文件称作「两者都要」已交付。

## 共用排版要求

三种模式都保持先中文后英文、逐段对应、不添加独立「中文 / English」标签行，间距沿用最新紧凑设置。PDF无需复制网页的所有边框或交互样式，但应保留清晰层次和相同学习内容。
